Interactivity Exploration

I extended my previous raining assignment by turning the static rain pattern into a continuous animation and made umbrella reall "works" by dragging it. Each raindrop is stored as an object in an array, with its own position and falling speed. When I drag the triangular umbrella across the canvas, it changes which raindrops are blocked. Like a real umbrella, it protects the area underneath from the rain. I asked our LLM a bit about what we learned last class because I wasn't there.
